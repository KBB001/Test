# 🚀 Инструкция по исправлению белого экрана на GitHub Pages

## Почему возникал белый экран? (Причина со скриншота)
На вашем скриншоте виден файл `index.html` на GitHub с кодом:
```html
<script type="module" src="/src/main.tsx"></script>
```
Когда в настройках GitHub Pages выбрана опция **Deploy from a branch $\rightarrow$ main / (root)**, GitHub Pages отдает исходный незакомпилированный файл. Браузер мобильного телефона не может выполнить сырой TypeScript-файл `.tsx` без сборки через Vite, в результате чего отображается пустой белый экран.

---

## Что исправлено в проекте:
1. **Создана папка `/docs` с готовой сборкой**: В ней уже лежат собранные минифицированные JavaScript и CSS файлы (`assets/`), готовые к моментальной работе в любом браузере.
2. **Добавлен `.nojekyll`**: Предотвращает ошибки обработки файлов движком Jekyll на серверах GitHub.
3. **Авто-перенаправление в корневом `index.html`**: Даже если случайно оставить `/(root)`, корневой файл автоматически направит браузер на скомпилированную версию в `/docs/`.

---

## Как включить сайт за 30 секунд:

### Способ 1: Переключить папку на `/docs` (Рекомендуется)
1. Откройте ваш репозиторий **[github.com/KBB001/Test](https://github.com/KBB001/Test)**.
2. Перейдите во вкладку **Settings** (Настройки) $\rightarrow$ в меню слева выберите **Pages**.
3. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: выберите `main`
   - **Папка (Folder)**: вместо `/(root)` выберите **`/docs`**!
4. Нажмите кнопку **Save**.
5. Подождите 30–60 секунд и обновите страницу **`https://kbb001.github.io/Test/`** — белый экран исчезнет, откроется платформа LinguaGlobus!

---

### Способ 2: Загрузить обновленный код на GitHub
Если вы работаете через терминал Git:
```bash
git add .
git commit -m "fix: compiled bundle in docs for GitHub Pages"
git push origin main
```
После отправки перейдите в **Settings $\rightarrow$ Pages** и выберите папку **`/docs`**.

---

### Способ 3: Через GitHub Actions
Если хотите полную автоматизацию при каждом push:
1. В **Settings $\rightarrow$ Pages** в поле **Source** выберите **GitHub Actions**.
2. Workflow `.github/workflows/deploy.yml` соберет и опубликует сайт автоматически.
