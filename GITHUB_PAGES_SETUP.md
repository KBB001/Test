# Пошаговая инструкция по публикации на GitHub Pages

## Шаг 1. Создание репозитория на GitHub
1. Откройте [https://github.com/new](https://github.com/new).
2. Задайте имя репозитория, например `linguaglobus`.
3. Оставьте чекбокс "Add a README file" **выключенным** (так как проект уже содержит все необходимые файлы).
4. Нажмите зеленую кнопку **Create repository**.

---

## Шаг 2. Загрузка проекта в GitHub
Откройте терминал в папке проекта и выполните следующие команды:

```bash
# 1. Инициализируем локальный git-репозиторий (если еще не инициализирован)
git init

# 2. Добавляем все файлы в коммит
git add .

# 3. Создаем первый коммит
git commit -m "Подготовка сайта к публикации на GitHub Pages"

# 4. Переименовываем ветку в main
git branch -M main

# 5. Привязываем ваш удаленный репозиторий на GitHub (замените URL на ваш!)
git remote add origin https://github.com/ВАШ_ЛОГИН/linguaglobus.git

# 6. Отправляем код на GitHub
git push -u origin main
```

---

## Шаг 3. Активация GitHub Pages

### Способ A: Автоматический через GitHub Actions (Самый современный и рекомендуемый)
В репозитории уже создан файл `.github/workflows/deploy.yml`. Все, что вам нужно:
1. Зайдите на страницу вашего репозитория на GitHub.
2. Перейдите во вкладку **Settings** (Настройки).
3. В левой колонке выберите **Pages**.
4. В выпадающем списке **Source** переключите с "Deploy from a branch" на **GitHub Actions**.
5. Через 1-2 минуты во вкладке **Actions** завершится сборка, и ваш сайт будет опубликован по адресу:
   `https://<ваш_логин>.github.io/linguaglobus/`

---

### Способ B: Через npm-команду
Если вы хотите опубликовать сайт вручную без настройки Actions:
```bash
npm run deploy
```
Эта команда автоматически соберет проект в папку `dist` и загрузит ее в специальную ветку `gh-pages`.
После этого в **Settings** -> **Pages** выберите ветку `gh-pages` и папку `/(root)`.

## Что было настроено в проекте:
1. **`vite.config.ts`**: Добавлен параметр `base: './'`, благодаря чему пути к JS, CSS и картинкам работают в подпапках GitHub Pages (`/repo-name/`) без ошибки 404.
2. **`package.json`**: Добавлены скрипты `"predeploy": "npm run build"` и `"deploy": "gh-pages -d dist"`.
3. **`.github/workflows/deploy.yml`**: Настроен CI/CD пайплайн для автоматической сборки при каждом push в ветку `main`.
4. **`public/404.html`**: Добавлен fallback-роутер для предотвращения ошибок 404 при обновлении страниц на GitHub Pages.
5. **Автономный режим (Offline Simulation)**: На GitHub Pages отсутствует сервер Node.js. Все функции (ИИ-наставник, перевод, карточки, озвучка и путеводитель) работают без сбоев прямо в браузере.
6. **Опциональный ввод API ключа**: Пользователи могут в любой момент указать свой личный Gemini API ключ в модальном окне настроек (кнопка в шапке сайта).
