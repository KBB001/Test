# 🌍 LinguaGlobus — Международная платформа коммуникации и изучения языков

Современная многоязычная платформа для живой коммуникации, языкового обмена и интервального повторения лексики.

---

## 🚀 Быстрый запуск на GitHub Pages

Проект полностью настроен для бесплатной публикации на **GitHub Pages**! 
Поддерживаются два удобных способа публикации: **Автоматический через GitHub Actions (рекомендуется)** и **Быстрый через npm-скрипт**.

### Вариант 1: Автоматический деплой через GitHub Actions (Рекомендуется)

1. **Создайте новый репозиторий на GitHub**:
   - Перейдите на [github.com/new](https://github.com/new).
   - Введите имя репозитория (например, `linguaglobus` или `lingua-app`).
   - Выберите **Public** (или Private).

2. **Отправьте код в репозиторий**:
   ```bash
   git init
   git add .
   git commit -m "feat: LinguaGlobus ready for GitHub Pages"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```

3. **Включите GitHub Pages в настройках репозитория**:
   - Откройте вкладку **Settings** репозитория на GitHub.
   - В левом меню нажмите **Pages**.
   - В блоке **Build and deployment** в поле **Source** выберите:
     👉 **GitHub Actions**.
   - Готово! Workflow `.github/workflows/deploy.yml` автоматически соберет проект и развернет его.
   - Ссылка на ваш работающий сайт появится в этом же разделе (обычно `https://<ваш-логин>.github.io/<имя-репозитория>/`).

---

### Вариант 2: Публикация в ветку `gh-pages` одной командой

В `package.json` уже настроен пакет `gh-pages`:

```bash
# Сборка и деплой в ветку gh-pages
npm run deploy
```

После завершения команды:
1. В настройках репозитория: **Settings** -> **Pages**.
2. В поле **Source** выберите **Deploy from a branch**.
3. Выберите ветку **gh-pages** и папку **/(root)**, нажмите **Save**.

## ⚡ Особенности работы на GitHub Pages

- **Относительные пути (`base: './'`)**: Приложение корректно загружает стили, скрипты и шрифты независимо от того, развернуто ли оно в корне домена или в подпапке `username.github.io/repo-name/`.
- **Автономный демонстрационный режим**: На GitHub Pages нет Node.js-сервера, поэтому приложение оснащено интеллектуальным встроенным симулятором:
  - Интерактивный чат с ИИ-наставником по сценариям («Разговорное кафе», «Подготовка к собеседованию» и др.).
  - Автоматическое извлечение лексики в интерактивные карточки со Spaced Repetition (SM-2 алгоритм).
  - Озвучка фраз через браузерный Web Speech API на всех поддерживаемых языках.
  - Культурные путеводители и адреса языковых клубов для Токио, Барселоны, Парижа, Берлина, Лондона.
- **Опциональный персональный Gemini API ключ**: В шапке сайта и в профиле есть кнопка **«GitHub / API»**, где любой пользователь может ввести свой бесплатный ключ Gemini API, чтобы активировать генерацию нейросетью прямо в браузере.

## 🛠 Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки (порт 3000)
npm run dev

# Проверка типов
npm run lint

# Сборка продакшн-бандла
npm run build
```
